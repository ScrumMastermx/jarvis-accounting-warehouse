# Programas (preescolar)

| Carpeta | Qué va aquí | ¿Se sube a git? |
|---|---|---|
| `planeaciones/` | Planeaciones didácticas generadas con `/planeacion` (sin nombres de alumnos) | Sí |
| `programa-analitico/` | Programa analítico del plantel por ciclo, con `/programa-analitico` | Sí (sin datos de familias) |
| `plantillas/` | Formatos vacíos: planeación semanal, lista de cotejo | Sí |
| `alumnos/` | Registros de evaluación y reportes con **nombres de alumnos** | **No. Privada.** |

Los datos de alumnos y familias (listas, expedientes, colegiaturas) van en `datos/escuela/`, también privada.
Regla completa: `.claude/rules/preescolar.md` y `.claude/rules/privacidad.md`.
