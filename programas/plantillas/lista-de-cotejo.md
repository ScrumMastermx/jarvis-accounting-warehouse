# Lista de cotejo (plantilla sin nombres)

- Campo formativo:
- Contenido: [Contenido: completar del programa analítico]
- PDA: [PDA: completar del programa analítico]
- Grado / grupo:
- Periodo (AAAA-MM-DD a AAAA-MM-DD):

Escala descriptiva (no es calificación): **Lo hace con apoyo** · **Lo hace solo** · **Aún no se observa**

| Indicador observable | Lo hace con apoyo | Lo hace solo | Aún no se observa | Observaciones (qué se vio, cuándo) |
|---|---|---|---|---|
| (Ejemplo: cuenta objetos hasta 5 al jugar) | | | | |
| | | | | |
| | | | | |

Para usarla con un grupo, copia la plantilla a `programas/alumnos/` y ahí pon los nombres. Esta versión no los lleva.
